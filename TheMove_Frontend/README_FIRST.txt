TheMove branded Streamlit frontend

1. Upload app.py, requirements.txt, and the entire assets/ folder to your GitHub repository.
2. Also upload your existing /content/themove_little_rock_places.csv from Colab to the repository root (same folder as app.py). This CSV is NOT included in this zip.
3. Streamlit Community Cloud: repository TheMove, branch main, main file app.py.
4. The app lets 2-5 friends rate activity categories, ranks them by group preferences, and finds nearby venues with geographic filtering.
5. This local venue ranking is RULE BASED, not your trained tourism recommender. Do not present it as an integrated ML/AI feature. The project still needs a tested AI explanation feature and final third-model assessment.
6. OpenStreetMap-derived data licensing/attribution and reuse terms must be checked before public redistribution.
